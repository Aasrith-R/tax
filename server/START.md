# Запуск сервера

## Текущая конфигурация

- **Порт:** 8080
- **Хост:** 127.0.0.1 (localhost)
- **База данных:** napoykmf_nds (MySQL)

## Запуск

```bash
cd server
npm run dev
```

Сервер будет доступен на: `http://127.0.0.1:8080`

## Проверка работы

Откройте в браузере или выполните:
```bash
curl http://127.0.0.1:8080/health
```

Должен вернуться JSON: `{"status":"ok","timestamp":"..."}`

## Изменение порта

Если порт 8080 занят, измените в `server/.env`:
```env
PORT=8081
```

И перезапустите сервер.

## Фронтенд

Фронтенд настроен на использование прокси через Vite, поэтому при запуске `npm run dev` в корне проекта, запросы к `/api` будут автоматически проксироваться на бэкенд.

Если запускаете фронтенд отдельно, убедитесь что `VITE_API_URL` в `.env` (корень проекта) указывает на правильный адрес бэкенда.
